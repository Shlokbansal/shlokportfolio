Engineering problem

Recharge validation needed a purpose-built setup that brought mechanical positioning, sensing, and test execution together. A useful prototype had to make the physical setup repeatable as well as make the electronics work.

My contribution

I designed and prototyped Arduino-based test systems, integrated sensors and precision motors, and developed 3D-printed components for the experimental setup. I also documented hardware, sensing, and fixture issues and helped verify corrective changes.

Technical approach

  • Build the physical setup

    Combined motors, sensors, and custom 3D-printed components into an electromechanical prototype.

  • Integrate control and testing

    Used Arduino-based control and automation workflows to support recharge-validation experiments.

  • Make the method transferable

    Authored SOPs and contributed to verification documentation so the setup could be operated and evaluated consistently.

Result

Electromechanical

prototype built for recharge validation

Delivered an integrated prototype and documented test workflow to support recharge validation. My work included troubleshooting hardware, sensing, and fixture interactions and checking implemented changes.

Public summary: prototype function and engineering contribution. Device geometry, motion profiles, sensor specifications, and internal validation data are omitted.

Lessons learned

The controller, fixture, and sensor cannot be debugged in isolation. A repeatable test depends on understanding how physical alignment and sensing interact, then documenting the setup well enough for another engineer to reproduce it.
