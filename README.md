# Shlok Bansal — Engineering Portfolio

Static portfolio for biomedical R&D, systems, and hardware-engineering interviews. The existing Vercel project serves the repository root; no framework, package installation, or build step is required.

## Pages

- `index.html`: background, selected projects, experience, and contact.
- `projects.html`: engineering project index, with recharge validation and laboratory refill featured first.
- `projects/*.html`: seven individual case studies with problem, contribution, approach, result, and lessons learned.
- `engineering.css`: shared navigation and project styling, including responsive layouts and reduced-motion support.
- `navigation.js`: accessible mobile-menu enhancement; links remain available without JavaScript.
- `assets/diagrams/*.svg`: original conceptual illustrations, not proprietary hardware drawings.

Project summaries describe individual contributions at a public level. Do not add internal drawings, confidential device geometry, unpublished test data, or employer photographs without authorization. Add numerical outcomes only when their basis and public use can be supported.

For a local review, serve the repository using any static HTTP server. Changes pushed to the Vercel-connected production branch deploy through the existing Vercel integration.
